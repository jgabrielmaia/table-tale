# Table Tale v0.1.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

The first alpha of Table Tale — a living library of board games and stories.

## Highlights

- Game library with search, filters, details, covers, and metadata.
- Session tracking, ratings, favorites, and personal progress.
- Google, GitHub, and magic-link authentication.
- Fate Draw: discover each player's card, faction, and identity.
- Profile with stats, achievements, and identity editing.
- Arcana & Elemental lore, events, and authenticated experiences.
- Responsive interface in Portuguese and English.
- Per-route SEO with prerendered pages, sitemap, robots.txt, JSON-LD, and `llms.txt`.
- Supabase PostgreSQL, Auth, Storage, RLS, migrations, and idempotent seeding.
- Unit, accessibility, responsive, and end-to-end test coverage.

## Deployment

The application is published under `/table-tale/` and requires the public Supabase environment variables and authentication provider configuration in production.

# Table Tale v0.12.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

Games get real pictures: openly licensed covers, and your own photo for the games you add.

## What's new

- **Real covers that actually show.** Uno, Dixit, Cores com Dicas and Baralho Clássico now show an openly licensed photo from Wikimedia Commons, with the author and licence credited under the picture on the game page. The old covers were linked from shop websites and never loaded on the site; games without an open photo show their illustrated cover until someone adds one.
- **A photo and an age for the games you add.** The **New game** form now takes an image (any size: it's shrunk before upload) and a recommended age, next to the title, description, players, duration and categories. The age shows on the game page.
- **No accidental duplicates.** Typing the name of a game that's already in the catalogue says so and offers to add that one instead, or tells you it's already on this shelf or in your collection.
- **Edit the games you added.** On the page of a game you added by hand, **Edit game** lets you change everything: title, description, players, duration, age, categories and picture. Games imported from BoardGameGeek keep BGG's data, so their owner still edits only the categories.

## For developers

- Database: `20261117000001_game_cover_age.sql` adds `games.cover_credit` / `cover_credit_url`, the public `game-covers` bucket (players write only under `<user id>/`, `catalogue/` is service-role only), the shared `check_game_input(...)`, `create_game(...)` with `p_min_age` and `p_cover_url` (the cover must be the caller's own upload), and `update_game(...)` for the owner of a hand-added game (BGG imports refused; replacing a cover drops its credit). Rollback file restores the previous `create_game`; CI assert `assert-game-cover-age.sql`. **Needs applying in production** (`npx supabase@latest db push --linked`) right after merging.
- Covers: `npm run covers` (`scripts/open-covers.ts`) copies the Commons files named in `seed-data.ts` (`openCover`) into `game-covers/catalogue/`, accepting only public domain, CC0, CC BY and CC BY-SA, and clears seed games' store hotlinks (blocked by the CSP). Run it once against production after the migration. `npm run seed` no longer writes `cover_url`, and the seed data no longer points at store websites.
- App: `NewGameModal` handles add and edit; new `src/features/games/cover.ts` (bucket constants, own-cover path guard, title matching); `useUpdateGame`. Script tests now run with Vitest (`scripts/**/*.test.ts`).
- No BoardGameGeek images: the BGG API is still waiting for approval, and Commons has no open photo for Hitster, Tranquility, Coup, Vaalbara or Duelo por Cardia.

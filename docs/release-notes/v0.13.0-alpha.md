# Table Tale v0.13.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

Edit a game you added right on its page, and see it as it will look.

## What's new

- **Edit on the page itself.** On the page of a game you added by hand, **Edit game** now turns the page into the editor: the title, description, players, duration and age are fields right where they show, the picture is replaced or removed under it, and categories are chips you add and remove. No more pop-up.
- **Always in reach.** A Save / Cancel bar stays on screen (above the tab bar on a phone). Cancel, or leaving, asks before throwing away what you changed; **Esc** cancels and **Ctrl/Cmd + Enter** saves. A title that another game already uses is flagged and can't be saved.
- Games imported from BoardGameGeek still let their owner edit only the categories.

## For developers

- App only, no migration: `src/features/games/GameInlineEdit.tsx` replaces the edit pop-up on `GameDetailPage`; `NewGameModal` still handles adding. Saving uses the existing `useUpdateGame` / `update_game`.

# Table Tale v1.1.0

A timer for your game nights, a sharper Lore, and a smoother way to develop locally.

## What's new

- **Game timer.** Track how long a session runs, right from the game page.
- **New artwork.** Fresh visuals across the library and game pages.
- **Skip the Fate Draw.** You can now skip the draw and come back to it later.
- **A shorter, more mysterious Lore.** The story of the two factions now reads in a few punchy lines instead of pages. It opens with a question and ends with a call to action: *Draw your card.*
- **Clearer reading path.** On the Lore page, each roman numeral now sits next to its icon.

## Changes you'll notice

- **English faction names are now Arcanists and Elementals** (previously "Arcanos" and "Elementais"). Portuguese keeps Arcanos and Elementais.
- The mobile language toggle stays visible.
- The home Lore call-to-action now uses a teal variant.

## For developers

- **Local auth bypass (development only).** With `VITE_LOCAL_AUTH_BYPASS=true` and a dev account in `.env`, `npm run dev` on localhost signs you in automatically, with no OAuth redirect. It uses a real Supabase session, so RLS and permissions behave as in production. It only activates on the Vite dev server and a localhost hostname. Production builds never enable it and contain no credentials. Setup: [docs/auth-setup.md](../auth-setup.md).
- Sign-in and sign-up callbacks now use local URLs when running locally.

## Fixes

- Removed the identity tooltip.
- Login callback redirects no longer point at the wrong host in local development.

# Table Tale v0.13.1-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

Removing someone from a community is no longer one click.

## Fixes

- **Confirm before removing a member.** **Remove** on a member now opens a window that names the player and asks you to type their name. The button stays off until the name matches (capitals and extra spaces don't matter). Cancel, **Esc** or tapping outside keeps them in. Rejecting a join request is unchanged.

## For developers

- App only, no migration: new `RemoveMemberDialog` and `nameMatches` helper in `src/features/communities/`, wired into `MembersPanel`.
- Issue: #97.

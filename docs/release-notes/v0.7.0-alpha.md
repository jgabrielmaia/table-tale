# Table Tale v0.7.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

Community pages now put the people behind the table front and centre.

## What's new

- **A real community cover.** Every community page now has a LinkedIn-style hero banner. Uploaded cover photos still take priority; communities without one receive a polished branded background instead of an empty space.
- **Owners are showcased.** Active owners are shown together below the hero, with their avatar and a direct link to their player page.
- **Co-ownership.** An owner can add any active member as a co-owner without displacing current owners. Owners can remove another owner's role when at least one owner remains. The original transfer action is still available when a complete handover is wanted.
- **Member shelves.** The Games tab can now be browsed as the whole community shelf, the community-owned shelf, or a shelf belonging to any member with copies in the collection.

## For developers

- Migration `20261113000003_community_coowners.sql` adds the `add_community_owner` and `remove_community_owner` RPCs. Both use the existing membership guard, so a community can never be left without an active owner.
- The member-shelf chooser is a view over the existing per-copy owner model; no game inventory is duplicated.

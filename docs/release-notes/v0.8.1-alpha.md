# Table Tale v0.8.1-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

A fix for signing in while running Table Tale locally.

## Fixes

- **Signing in on localhost brings you back to localhost.** Google, GitHub and magic-link sign-in from a local copy of the app used to land on the live site instead of returning to `localhost`. You now come back to the page you were trying to open. Signing in on the live site is unchanged.

## For developers

- Root cause: the callback sent to Supabase was `…/auth/callback?next=<path>`. Supabase matches it against the project's Redirect URLs, and the exact `localhost` entry stops matching once `?next=` is appended, so Supabase fell back to the Site URL (production).
- The callback URL is now always `…/auth/callback`. The post-login destination is kept in `localStorage` (`tt:auth-next`), validated by `safeNextPath`, and cleared by `/auth/callback` once used. `?next=` in the query is still honoured for links sent before this release.
- No database or Supabase dashboard changes. `docs/auth-setup.md` describes the flow.

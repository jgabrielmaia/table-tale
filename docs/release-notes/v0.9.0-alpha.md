# Table Tale v0.9.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

The home page now opens with the games you played last.

## What's new

- **Recently played first.** The home page shows the games you played most recently, newest first, with when you last played each one ("Played 3 days ago"). Logging a session or marking a game as Playing or Played moves it to the front.
- **Your community's favourites fill the rest.** If you haven't played anything yet, or only a game or two, the section fills up with the games most played in your communities over the last 90 days, with how many members played each one.
- **Popular games for everyone else.** Visitors and players who haven't joined a community see the games most played on public community shelves.

## For developers

- New migration `20261114000002_shelf_highlights.sql`: `shelf_highlights(p_limit)` (security definer, granted to `anon` and `authenticated`), an internal `community_game_popularity()` clients can't call, and the index `game_sessions (game_id, played_at desc)`. It returns per-game totals only, never another member's sessions. The public ranking only includes games on a public shelf, so a game kept on a private shelf never reaches visitors through a member's plays.
- The migration must be applied in production before this version is deployed: the home page calls the function. Rollback in `supabase/rollbacks/`, CI assertion in `supabase/ci/assert-shelf-highlights.sql`.
- The highlights query key is part of `progressKeys`, so session and status changes refresh it. `GameCard` takes an optional `note` line.

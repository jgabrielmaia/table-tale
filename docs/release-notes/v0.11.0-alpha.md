# Table Tale v0.11.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

Add games by hand and shape their categories, no BoardGameGeek needed.

## What's new

- **Add a game without BGG.** On a community's Games tab and in "My games", the new **New game** button adds a game that isn't in the catalogue yet: title (required), description, players, duration and categories. The game goes straight onto that shelf or into your collection, and you become its owner. "Add from the catalogue" is now clearly labelled, and its "Choose a game…" row is a placeholder, not a choice.
- **Edit a game's categories.** The person who added a game (or imported it from BGG) gets **Edit categories** on its page: add and remove as many as they like. The label above the title, the cards and the category filter use them. Games that were already here belong to the collection owner.
- **Fewer BGG leftovers.** "BGG rating" in the Sort by menu now only appears while the BoardGameGeek feature is on.

## Fixes

- "BGG rating" no longer shows in Sort by on the games page and on a community's Games tab while BGG is off.

## For developers

- Database: `20261115000001_game_owner.sql` adds `games.owner_id` (existing games backfilled to the `OWNER_EMAIL` account, BGG imports set the importing user), lets only the owner update a game and only its `categories` (column grant plus RLS), and checks category lists (at most 30 labels of 1 to 60 characters). `20261115000002_create_game.sql` adds `create_game(...)`: validated, caller becomes the owner, free slug picked, at most 20 games per account per day. Both have rollback files and CI asserts. Both are applied in production before the release.
- App: `src/features/games/` gets `CategoryPicker` (chips + field, shared by the editor and the new-game form), `GameCategoriesEditor`, `NewGameModal`, `NewGameButton`, `categories.ts` and `newGameSchema`. `availableSorts()` builds the Sort by menu from the BGG flag. `Select` options can be `disabled`.
- BGG import (`bgg` Edge Function): a new game is inserted with `owner_id`; linking an existing game keeps its owner; a re-sync never overwrites categories that are already set.

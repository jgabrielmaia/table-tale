# Table Tale v0.14.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

The shared catalogue gets hundreds of real games, for every community, and finding one is a matter of typing.

## What's new

- **A catalogue to pick from.** The 500 most popular board games from a BoardGameGeek dataset join the shared catalogue (title, players, play time, recommended age, year, categories and mechanics, plus BGG's rank and rating). Every community can put any of them on its shelf, and every player in their own library. Games that were already there, or have the same title as one someone added, are left as they are.
- **Search to add.** "Add from the catalogue" is now a search box: type part of a name (accents and capitals don't matter), pick from the list with a tap, a click, or the arrow keys and Enter. It says when nothing matches.
- **Credit.** The footer credits the game data (BoardGameGeek, via the Kaggle dataset, CC BY 4.0).
- Imported games have no description and no picture: those belong to BoardGameGeek and the publishers. They show their illustrated cover, and anyone can still add a game by hand.

## For developers

- App only, no migration. `npm run catalogue:import -- --ratings ratings.csv --details details.csv [--top 500] [--dry-run]` (`scripts/catalogue-import.ts`, service role, run by hand) reads the TidyTuesday 2022-01-25 `ratings.csv` and `details.csv` (made from the Kaggle "Board Games" dataset, a February 2021 snapshot) and inserts the top games by BGG rank. Safe to re-run: skips games by BGG id and by title. It refuses to grow the catalogue past 1000 games, because the app loads the catalogue in one query and the API returns at most 1000 rows; going past that needs server-side search and paging first.
- New `src/features/games/GamePicker.tsx` (ARIA combobox) replaces the plain selects on the community shelf and in "My games".

# Table Tale v0.10.0-alpha

> **Alpha.** Table Tale is still in alpha: features, data and URLs may change between versions.

Use any photo for your community cover or profile picture, straight off your phone.

## What's new

- **No more size limit on photos.** Community covers and profile pictures used to stop at 2 MB and 1 MB. Now any PNG, JPEG or WebP photo works: Table Tale shrinks it in your browser before uploading (covers to 3000 px wide, profile pictures to 512 px), so pages stay quick to load.
- **Clearer message for broken files.** A file that isn't a readable image now says so, instead of failing on upload.

## For developers

- New `src/lib/image.ts`: `shrinkImage(file, target)` scales with a canvas and encodes WebP (JPEG fallback where the browser can't write WebP), lowering quality until the file fits the bucket limit. Photos that already fit are sent unchanged.
- Covers shrink inside `setCommunityCover`, so both the Manage tab field and the "Edit cover" button on the community page get it. Avatars shrink when picked, so the preview shows what will be uploaded.
- Storage bucket limits are unchanged (2 MB covers, 1 MB avatars). No database changes.
- E2E: `tests/utils/images.ts` builds real PNGs, and the fake backend now records uploads (type, bytes, pixel size).
